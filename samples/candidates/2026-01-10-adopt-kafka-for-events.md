# Adopt Kafka for cross-service event streaming

## Context

The proposed shared event bus (see the platform project's "Adopt a
shared event bus" record) has two competing concrete implementation
proposals; this is one of them.

## Decision (proposed)

Adopt Apache Kafka as the event streaming backbone.

## Demo note

This candidate is pushed, then **rejected** by a reviewer with a
comment, to demonstrate the reject flow. A rejection applies only to
this exact content hash; a revised proposal would need its own
decision.
